# Triage Labels

| Canonical role    | Label in this repo | Meaning                                                       |
| ----------------- | ------------------ | ------------------------------------------------------------- |
| `needs-triage`    | `needs-triage`     | Maintainer needs to evaluate this issue                       |
| `needs-info`      | `needs-info`       | Waiting on the reporter for more information                  |
| `ready-for-agent` | `ready-for-agent`  | Fully specified, ready for an agent                           |
| `ready-for-human` | `ready-for-human`  | Requires human implementation                                 |
| `wontfix`         | `wontfix`          | Will not be actioned                                          |
| `complete`        | `complete`         | Acceptance criteria are met or explicitly closed by the owner |

When a skill mentions a triage role, use the matching label above.
