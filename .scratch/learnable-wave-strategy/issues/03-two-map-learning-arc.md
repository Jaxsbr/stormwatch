# 03: Plan the two-map learning arc

**What to build:** A reviewable wave plan that teaches approved enemy behaviors safely, gives players a chance to practice, then combines familiar threats across Lantern Pass and Rainstone Crossing. The routes and terrain should create different placement choices and give the expedition a clear sense of progression.

**Blocked by:** None. Ticket 02 is complete; the rat guard is already in the game.

**Status:** ready-for-agent

- [ ] Place the approved Rat Raider guard, then proposed later enemy behaviors into a low-risk first sighting, a clearer practice encounter, and a later combination with learned threats.
- [ ] Show which route and terrain differences make useful placements change between the two existing maps while preserving fixed paths.
- [ ] Identify where tower mix, placement, upgrades, or spending choices can matter; do not rely only on increasing health, speed, damage, counts, or wave length.
- [ ] Keep the first lesson forgiving and describe how a weak or greedy plan can later leak or lose for a visible, learnable reason.
- [ ] Keep supporting story and learning cues short and visual-first; treat any recap text as optional unless review shows it is needed.
- [ ] Present a concrete wave order and map roles for owner review before changing encounter content. Exact later abilities remain proposals until selected.

## Reconciliation

This is the next ticket. The current game already gives every rat a periodic guard in the existing waves; those wave groups were not authored as a teach → practice → combine lesson. Start by checking whether a first sighting is forgiving and whether two tower plans or placements respond differently. The saved broad and focused plans still win both maps with 12 hearts, while the greedy opening loses more hearts in wave 1. Use the current [scenario check](../../../review/2026-09-25-learnable-wave-strategy/reconciliation-2026-09-25.md) when planning the arc.
